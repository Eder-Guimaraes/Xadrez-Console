# ♟️ Xadrez Console

Um sistema de xadrez desenvolvido em **C#** utilizando os princípios de **Programação Orientada a Objetos (POO)**.

Este projeto foi desenvolvido como parte do curso de C# do professor **Nélio Alves**, com o objetivo de aplicar conceitos de orientação a objetos na implementação das regras oficiais do jogo de xadrez.

---

## 📖 Sobre o projeto

O projeto simula uma partida de xadrez em modo console, permitindo que dois jogadores realizem suas jogadas diretamente pelo terminal.

Durante o desenvolvimento foram aplicados conceitos fundamentais de desenvolvimento de software, como modelagem de classes, encapsulamento, herança, polimorfismo e separação de responsabilidades.

---

## 🚀 Funcionalidades

* ♟️ Movimentação de todas as peças
* ✅ Validação de jogadas
* ⚠️ Detecção de xeque
* 👑 Detecção de xeque-mate
* 🎮 Alternância automática entre os jogadores
* 📌 Controle do estado da partida

---

## 🛠️ Tecnologias utilizadas

* C#
* .NET
* Programação Orientada a Objetos (POO)

---

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/Eder-Guimaraes/Xadrez-Console.git
```

Acesse a pasta do projeto:

```bash
cd Xadrez-Console
```

Abra a solução no **Visual Studio** e execute o projeto.
