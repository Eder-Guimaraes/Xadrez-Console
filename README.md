# ♟️ Xadrez Console

Projeto desenvolvido em **C#** utilizando **Programação Orientada a Objetos**, baseado no curso do professor Nélio Alves.

## 📚 Tecnologias

- C#
- .NET
- Programação Orientada a Objetos (POO)

## 🚀 Funcionalidades

- Movimentação das peças
- Validação de jogadas
- Xeque
- Xeque-mate

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Eder-Guimaraes/Xadrez-Console.git
```

2. Abra a solução no Visual Studio.

3. Execute o projeto.
